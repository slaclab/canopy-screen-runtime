# @slaclab/canopy-dock-engine

The workspace dock's layout engine: the layout tree and its validation,
geometry, drop planning, open/close/reopen and hit-testing, as pure functions
with no DOM and no dependencies. The golden case files in `cases/` pin its
behaviour; `./cases` is the runner that replays them against any
implementation of the engine.

- `src/` and `cases/` are the source. A rule change changes its cases first.
- `dist/` is generated by `pnpm --filter @slaclab/canopy-dock-engine build` and
  committed, so a host that embeds the dock can vendor `dist/dock-engine.mjs`
  (types in `dist/dock-engine.d.mts`) at a commit of this repository. A test
  fails when `dist/` is stale.
- The viewer reads the source through the `canopy-source` export condition.

Not published to a registry.
