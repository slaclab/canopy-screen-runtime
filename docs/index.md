# Canopy Screen Runtime

Runs the screens built with
[canopy-screen-builder](https://github.com/slaclab/canopy-screen-builder):
the Screen IR renderer, the widget set, and **Canopy Screens**, the
operator-facing viewer.

Content (the screens themselves) lives in
[canopy-screens](https://github.com/slaclab/canopy-screens); live data comes
from [Canopy](https://github.com/slaclab/Canopy).

## The viewer

- [The dock](dock.md): tiles and tabs, where a drag lands, the ☰ window
  menu, and getting closed screens back.
- [Host embedding](host-embedding.md): running the workspace as a tile of a
  host shell, and the messages the two exchange.
